# Working agreement

This repo is shared only between two people. Skip the pull-request process.

- **No pull requests.** Don't open PRs, draft PRs, or ask about opening one.
- **Commit straight to `main` and push it** (`git push -u origin main`). Don't create
  `claude/...` or other feature branches unless asked.
- **Write commit messages like PR descriptions**: a short summary line, a blank line,
  then a body covering what changed and why, as bullet points, plus anything
  worth testing or knowing about.
